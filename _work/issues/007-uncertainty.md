## Goal

Show how far each rating can be trusted.

## Acceptance criteria

- [ ] Bootstrap by match (about 200 draws) giving an 80 % band per rating
- [ ] "Inseparable" flag when a player's on-court pattern correlates above 0.95 with a teammate's
- [ ] "Small sample" flag below 100 rallies in the window
- [ ] Liberos marked "n/a, inside the team term"
