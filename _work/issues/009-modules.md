## Goal

Build the three uses on top of the profiles. Each can later be split into its own issue.

## Acceptance criteria

**Scouting**
- [ ] Opponent players ranked by impact, with bands and flags; best and weakest servers
- [ ] Rotation table: sideout % and break % per rotation, observed vs expected
- [ ] Usual starting six and substitution habits

**Line-up**
- [ ] Line-up predictor: any six against an opponent's usual six → sideout %, break %, P(set win)
- [ ] Side-by-side comparison of candidate line-ups

**Form**
- [ ] Alert when form leaves the season band two match days in a row
- [ ] Team view of the biggest form changes since the last report
